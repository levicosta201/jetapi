JetAPI Documentation

JetAPI é uma API REST que fornece informações sobre aeronaves, incluindo fotos do JetPhotos e dados de voos do FlightRadar24. Todas as imagens são otimizadas e servidas via CloudFront para máxima performance.

🌐 Base URL

📡 Endpoint Principal

GET
/api

Retorna informações sobre uma aeronave, incluindo fotos e histórico de voos.

📋 Parâmetros da Requisição

Parâmetro Tipo Obrigatório Descrição
reg string Sim Matrícula da aeronave
Formato: alfanumérico (pode incluir hífen)
Exemplos: PR-MHK, N123AB, G-ABCD
photos integer Não Número de fotos mais recentes
Padrão: 3
Mínimo: 0 | Máximo: 20
flights integer Não Número de voos mais recentes
Padrão: 20
Mínimo: 0 | Máximo: 20
only_jp boolean Não Buscar apenas no JetPhotos
Valores: true ou false
Padrão: false
only_fr boolean Não Buscar apenas no FlightRadar24
Valores: true ou false
Padrão: false

💡 Exemplos de Uso

Exemplo 1: Busca completa (fotos + voos)

GET /api?reg=PR-MHK

Retorna 3 fotos e 20 voos mais recentes (valores padrão)

Exemplo 2: Especificando número de fotos e voos

GET /api?reg=PR-MHK&photos=5&flights=10

Retorna 5 fotos e 10 voos mais recentes

Exemplo 3: Apenas fotos do JetPhotos

GET /api?reg=PR-MHK&only_jp=true&photos=10

Retorna apenas 10 fotos do JetPhotos, sem dados de voos

Exemplo 4: Apenas dados de voos

GET /api?reg=PR-MHK&only_fr=true&flights=15

Retorna apenas 15 voos do FlightRadar24, sem fotos

Exemplo 5: Apenas informações básicas (sem fotos nem voos)

GET /api?reg=PR-MHK&photos=0&flights=0

Retorna apenas informações básicas da aeronave

🔢 Códigos de Status HTTP

Código Significado Descrição
200 OK Requisição bem-sucedida, dados retornados
400 Bad Request Parâmetros inválidos (ex: matrícula com caracteres especiais)
404 Not Found Aeronave não encontrada ou sem dados disponíveis
405 Method Not Allowed Método HTTP não permitido (apenas GET é suportado)
500 Internal Server Error Erro interno do servidor

⚡ Performance e Cache

Cache Inteligente

  • Redis Cache: Resultados são cacheados por 24 horas para respostas instantâneas
  • S3 Storage: Imagens são baixadas e armazenadas no S3, evitando downloads repetidos
  • CloudFront CDN: Todas as imagens são servidas via CloudFront para máxima velocidade global

💡 Dica: A primeira requisição pode ser mais lenta (download e upload de imagens). Requisições subsequentes são extremamente rápidas graças ao cache.

💻 Exemplos de Código

JavaScript (Fetch API)

fetch('/api?reg=PR-MHK&photos=5')
  .then(response => response.json())
  .then(data => {
    console.log('Fotos:', data.JetPhotos.Images);
    console.log('Voos:', data.FlightRadar.Flights);
  })
  .catch(error => console.error('Erro:', error));

Python (requests)

import requests

response = requests.get('http://localhost:8080/api', params={
    'reg': 'PR-MHK',
    'photos': 5,
    'flights': 10
})

data = response.json()
print(data['JetPhotos']['Images'])
print(data['FlightRadar']['Flights'])

cURL

curl "http://localhost:8080/api?reg=PR-MHK&photos=5&flights=10"

⚠️ Limitações e Notas

  • A API funciona melhor com aeronaves comerciais
  • Aeronaves de aviação geral (GA) podem causar erros devido à variabilidade nas páginas do FlightRadar
  • Matrículas não encontradas retornam erro 404
  • O número máximo de fotos e voos é 20 por requisição
  • Imagens são automaticamente otimizadas e servidas via CloudFront
